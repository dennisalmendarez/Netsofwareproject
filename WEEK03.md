# Project Overview

Anime & Movie Tracker is a .NET Blazor web application designed to help users organize and manage anime series and movies they have watched, are currently watching, or plan to watch in the future. Many users struggle to keep track of large watchlists across multiple streaming platforms, making it difficult to remember progress, ratings, and favorite titles. This application provides a centralized platform where users can store and organize their entertainment preferences in a clean and user-friendly dashboard.

The application is targeted toward anime fans, movie enthusiasts, students, and casual viewers who want a better way to manage their personal watchlists. Users will be able to create accounts, search and filter titles, rate content, and organize entries based on watch status and genre. The project focuses on usability, responsive design, and personalized entertainment tracking.

What makes this project valuable is its combination of entertainment organization, personalized tracking, and recommendation features within a modern .NET Blazor application. The project also provides practical experience with authentication, CRUD operations, responsive web design, and database management.

# App Features

- Users can create accounts and securely log in.
- Users can add anime and movie titles to their personal watchlist.
- Users can update watch status such as Watching, Completed, Want to Watch, or Dropped.
- Users can rate anime and movies.
- Users can search and filter titles by genre, year, rating, or watch status.
- Users can mark titles as favorites.
- Users can edit or delete existing watchlist entries.
- Users can access the application on desktop, tablet, and mobile devices.

---

# User Stories

- As a user, I want to create an account so I can securely save my watchlist.
- As a user, I want to track what anime or movies I am currently watching so I can manage my progress.
- As a user, I want to search my watchlist by genre or status so I can quickly find titles.
- As a user, I want to rate titles so I can remember which ones I enjoyed most.
- As a user, I want to save favorite titles so I can easily revisit them later.

# Technical Considerations

## Data Storage
The application will store:
- User account information
- Anime and movie entries
- Watch status
- Ratings
- Genres
- Favorite selections
- Notes and comments

## User Accounts
Users will create accounts and log in securely using ASP.NET Core Identity authentication.

## External Services
The initial version will not rely heavily on external APIs. Optional future improvements may include anime or movie database APIs.

## Device Compatibility
The application will support desktop, tablet, and mobile devices using responsive design principles.

## Basic Security
- Password hashing and authentication using ASP.NET Core Identity
- Authorization for protected user data
- Validation of user input
- Protection against unauthorized account access
